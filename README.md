### Excersize to work with server Api.

## The tech stach are:

- Native JS (OOP)
- Typescript
- SASS(SCSS) with the BEM methodology
- Webpack for dev server and the project build

## In order to launch this project locally you will need to:

- clone repository with backend app located [here](https://github.com/mikhama/async-race-api#start--stop-cars-engine)
- start server via its instructions (npm i, npm start)
- clone the project repo
- npm i to install all the required dependencies
- npm run dev to start your local dev server.
